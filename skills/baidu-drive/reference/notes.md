# 开发笔记与注意事项

本文档包含 Skill 开发阶段的注意事项和内部说明，**不面向最终用户**。

---

## 安全须知

安全须知统一使用 [SKILL.md「登录确认」](../SKILL.md#登录确认)中的固定话术；使用完可注销，注销命令为 `bdpan logout`。

**首次进入新的授权流程时，按主 SKILL 展示安全须知，并在普通对话中取得用户明确确认。**

---

## 内部实现说明

### Agent 安全限制

所有 Agent 安全约束（登录方式、Token 保护、更新控制、环境变量、路径安全）集中定义在 [SKILL.md](../SKILL.md) 的「安全约束」章节。此处不再重复，维护时以 SKILL.md 为准。

### 授权后继续使用

使用 CLI 返回的完整授权链接，支持跨设备完成网页授权。下一次业务请求才领取凭据并执行，服务端链接即使含 `key` 也原样展示，不截断或去除参数；不单独读取或输出 key、code、Token 或配置文件，不从聊天原文透传凭据。详见 SKILL.md「授权后继续使用」章节。
